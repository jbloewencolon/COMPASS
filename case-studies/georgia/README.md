# Georgia reference case study

This pack contains the Georgia Technology Authority (GTA) materials uploaded in
commit `77b97ab` on 6 November 2026. Its baseline and proposed amendments are
dated 27 July 2026. It is a reference case, not the default configuration or
legal authority for other states.

**Review status:** original files are preserved byte-for-byte. Historical legal
assertions and acceptance statements have not been validated by organizing the
files. Treat proposed outputs as material for review, not evidence of authorized
approval or adopted policy. See [open review items](REVIEW-STATUS.md).

## Preservation and variants

The upload contained 83 file paths, representing 39 distinct byte contents:
38 substantive files and one `desktop.ini` metadata file. Exact duplicate copies
were consolidated; every original path maps to a byte-identical retained file
in the [upload manifest](provenance/upload-manifest.csv).

Three documents have distinct variants: Prompt 01, the amendment cards, and the
review-cycle guide. Both versions of each are retained. The copy in an ordinary
folder follows the top-level upload; the alternate from the nested upload is in
`archive/variants/`. This placement does not establish which version is approved,
newer, or authoritative. That requires reconciliation by the policy owner.

All 24 distinct `.docx` files in this upload are Word-format ZIP packages, and all
four distinct `.xlsx` files are workbook-format ZIP packages. They were not
renamed from plain text. The Markdown baseline, package, and scan remain `.md`.

Original filenames and embedded historical references are retained. If a Word
document refers to its former sibling/folder layout, use the catalog and manifest
to find the moved file. No new approval, source verification, or legal correction
has been written into those originals.

## Reuse in another state

Start from the [neutral method](../../method/README.md), supply a new jurisdiction
intake, and verify the applicable instruments and sources. Do not carry over GTA
instrument numbers, Georgia legislative dates, authorities, findings, or decisions.
The document pack is not automatically imported into the application; its demo
database continues to contain synthetic fixtures.
