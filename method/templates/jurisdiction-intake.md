# Jurisdiction intake worksheet

**Status:** draft; complete before using the method for a real jurisdiction.
This is a manual worksheet, not a runtime configuration schema loaded by COMPASS.

| Item | Jurisdiction-specific information to supply |
|---|---|
| Jurisdiction and office | Identifier, name, issuing/maintaining office, policy owner |
| Covered entities and activities | Agencies/programs, vendors, exclusions, shared-service interfaces |
| Instrument inventory | Stable IDs, titles, versions, source locations, dates, full text |
| Authority and hierarchy | Actual local instrument families; which may create duties and within what scope |
| Definitions | Exact defined terms, local terminology, non-equivalent external terms |
| Applicable sources | Statutes, regulations, orders, grant/contract conditions, adopted standards; known exceptions |
| Verification | Source type, verification status/date/checker, primary-source location, unresolved questions |
| Records and disclosure | Retention schedules, access restrictions, required artifacts, publication route |
| Review calendar | Owner-set cadence, event triggers, actual legislative sessions and bill carryover rules |
| Decision rights | Authorized decision-maker, review/delegation rules, counsel and procurement routes |
| Prior work | Baseline/run IDs, source and governance registers, unresolved/settled findings |
| Priority rubric | Approved dimensions, thresholds, tie handling, and critical-error treatment |
| Coverage limitations | Missing sources, uncertain extraction, unknown applicability, unavailable expertise |

Policy-owner confirmation: **not recorded**.

Do not copy dates, source applicability, or approval status from another
jurisdiction. Record each confirmation with a person, date, and supporting basis.
